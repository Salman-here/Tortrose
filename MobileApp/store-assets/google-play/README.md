# Google Play assets

- `app-icon-512.png`: 512 × 512 Play listing icon exported from the approved full-bleed launcher artwork.
- `feature-graphic.png`: 1024 × 500 branded feature graphic.
- `listing-en-GB.md`: approved listing copy and Store settings proposal.
- `release-notes-en-GB.md`: release notes for Android 1.0.9 (version code 10).
- `data-safety.md`: code-backed worksheet for the Play Data Safety declaration.
- `phone/`: reserved for 4–8 current in-app screenshots. Use real current-build screens at 1080 px or wider before uploading.

Do not upload fabricated UI screenshots. Capture the current Android build, then add optional branded captions or device framing without changing what the app actually shows.
